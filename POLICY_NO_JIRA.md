# No Jira Policy

We do not use Jira or any external ticketing system for this repository.

- No Jira tickets will be created for any work items.
- All planning, tracking, and discussion are done in GitHub:
  - Use GitHub Issues for bugs and tasks.
  - Use GitHub Discussions for feature requests and broader design conversations.
  - Reference issues in PRs with GitHub keywords (e.g., "Closes #123").
- Confluence is not used for documentation. Prefer in-repo docs (e.g., README, docs/), or GitHub Discussions for long-form notes.

Rationale: keep everything close to the code, transparent, and versioned.
